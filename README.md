# Seasonal Agriculture Performance Analysis Using Data Visualization

## 📌 Project Overview

This project focuses on analyzing agricultural performance across different seasons using data visualization and exploratory data analysis techniques.

The dataset contains information related to crops, seasons, locations, irrigation methods, environmental conditions, resource usage, yield, production, cost, revenue and profit.

The main aim of this project is to understand how agricultural performance varies across **Kharif, Rabi and Zaid** seasons and to identify meaningful patterns and relationships in the data.

---

## 🎯 Objectives

- Analyze agricultural performance across different seasons.
- Compare crop yield between Kharif, Rabi and Zaid seasons.
- Study crop-wise agricultural performance.
- Analyze the relationship between environmental factors and crop yield.
- Understand the impact of resources such as fertilizer, water and pesticides.
- Compare seasonal profitability.
- Identify profitable crop-season combinations.
- Present agricultural insights using clear and meaningful visualizations.
